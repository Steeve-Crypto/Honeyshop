# Honeyshop Web UI

Astro multi-page dashboard (obsidian + gold).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Overview |
| `/live` | Interaction feed |
| `/services` | SSH / HTTP / FTP status |
| `/alerts` | Detections |
| `/settings` | Ports & integrations |

## Run

```bash
cd web
npm install
npm run dev
```

Open http://localhost:4321
